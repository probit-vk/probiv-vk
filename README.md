## Быстрый старт — пробить ВК за 10 секунд

### Вариант 1 — ТГ бот (рекомендуется)

```text
1. Открой [bot-probiv.org](https://bot-probiv.org/)  (замени на свой)
2. Нажми /start → /probiv
3. Пришли что угодно из списка:
   • https://vk.com/id123456
   • https://vk.com/durov
   • id123456
   • @durov
   • +79161234567
   • фото человека
4. Получи отчет: телефон, профиль, друзья, фото, с кем общается, активность
```

### Вариант 2 — API / код

```bash
curl -X POST https://bot-probiv.org/v1/probiv \
  -H "Content-Type: application/json" \
  -d '{"query": "https://vk.com/id123456"}'
```

```python
# python — пробить человека по вк через api
import requests
for q in ["https://vk.com/id123456", "+79161234567", "@durov", "id123456"]:
    r = requests.post("https://bot-probiv.org/v1/probiv", json={"query": q})
    print(q, r.json().get("status"))
```

```javascript
// node — пробить по айди вк / по ссылке вк / по юзу
fetch("https://bot-probiv.org/v1/probiv", {
  method: "POST",
  headers: {"Content-Type":"application/json"},
  body: JSON.stringify({query: "durov"}) // юз без @
}).then(r=>r.json()).then(console.log)
```

> **Подсказка:** бот принимает `для пробива вк` любой формат — ID, ссылка, юз, номер телефона, фото. См. отдельные гайды: [по номеру](https://github.com/probit-vk/probiv-vk-po-nomeru-telefona), [по айди](https://github.com/probit-vk/probiv-vk-po-id-ssylke-yuzu), [по ссылке](https://github.com/probit-vk/probiv-vk-po-id-ssylke-yuzu#пробить-по-ссылке-вк).

## FAQ

### Можно ли пробить вк?
Да. Через [тг бота](https://github.com/probit-vk/probiv-vk-bot) можно пробить вк по ID, ссылке, юзу, номеру, фото. Работает и для закрытых профилей (показывает доступные данные).

### Как пробить человека по вк?
Кидай боту ссылку `https://vk.com/id...` или `vk.com/username` или `id123456`. Команда: `/probiv https://vk.com/id123456`. См. раздел [Пробить человека по вк](#пробить-человека-по-вк).

### Как пробить вк по номеру телефона?
Отправь номер `+79161234567` боту. Или наоборот — кинь ссылку на страницу и бот попробует найти номер. Подробно: [по номеру](https://github.com/probit-vk/probiv-vk-po-nomeru-telefona).

### Как пробить закрытый вк?
Так же как открытый — по ID/ссылке. См. [закрытый вк](https://github.com/probit-vk/probiv-vk-zakryty-foto-druzya).

### Есть ли бесплатный бот пробив вк?
Да, есть пробный бесплатный режим (1-3 запроса/день) и [бесплатные боты](https://github.com/probit-vk/probiv-vk-besplatno-online).

### Чем отличается пробить страницу / профиль / аккаунт вк?
Ничем — синонимы. Страница = профиль = аккаунт. Бот понимает все варианты.

### Что такое пробив по айди / по ссылке / по юзу?
- **по айди** — `id123456`
- **по ссылке** — `https://vk.com/...`
- **по юзу** — `durov` (часть после `vk.com/`)
Все три — один и тот же пробив, см. [по айди/ссылке](https://github.com/probit-vk/probiv-vk-po-id-ssylke-yuzu).
